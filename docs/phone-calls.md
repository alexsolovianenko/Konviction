# Konviction telephone calls

Konviction uses the existing ElevenLabs agent and its production branch. Native Twilio delivers the call. Market search and quotes use the public Gemini Sandbox endpoints. Private phone tools verify the provider webhook secret, fetch the active conversation from ElevenLabs, and match its agent, branch, Twilio number ID and external phone number. Browser sessions cannot supply that identity. A second factor authenticates the person who answered. Outbound calls offer a private update and disclose the settlement after verification.

## Operator setup

1. Set server-only environment variables in the existing Vercel project. Keep the existing ElevenLabs, voice confirmation and Blob credentials. Set `ELEVENLABS_PHONE_NUMBER_ID` to the imported phone ID and `CRON_SECRET` to a random secret. For number provisioning only, run `node scripts/connect-twilio.mjs` in a trusted environment containing `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`, `ELEVENLABS_API_KEY`, `ELEVENLABS_AGENT_ID` and `ELEVENLABS_BRANCH_ID`. ElevenLabs stores the native Twilio credential. The application runtime needs only the ElevenLabs credential for dialing.
2. Enroll each verified owner in the sensitive production variable `PHONE_ACCOUNTS_JSON`, a JSON array. Each record needs a stable unique `id` of lowercase letters, digits or hyphens, the owner's verified E.164 `phone`, their dedicated Gemini Sandbox `apiKey` and `apiSecret`, and a unique 32-character Base32 `totpSecret` shared privately with their authenticator (SHA-1, six digits, 30 seconds). Verify that each credential actually belongs to a distinct sandbox account, including across key rotations. Reserve the public browser demo account for the dashboard. Never reassign an enrollment ID to a different owner. Verify the new number with the owner before changing a registration. Removing the enrollment revokes phone access.
3. With the owner's consent, set `notifySince` on that record to the UTC timestamp when settlement notifications should start. Omit it to disable outbound calls. Redeploy after changing production variables. With no enrolled accounts, the phone line supports public market questions and refuses all private operations.
4. Run `node scripts/publish-phone-tools.mjs` with the existing agent environment. It derives the production origin and workspace-secret reference from the existing hosted trading confirmation tool. It attaches the telephone tools and appends the telephone instructions to the existing prompt.
5. Verify a real inbound call, spoken OTP, portfolio lookup and a separate exact proposal readback. Test one outbound settlement with a consenting registered owner. Canadian and US registrations retain their international +1 number while traveling.

## Settlement delivery

A Vercel Queue renews an authenticated Gemini Sandbox position-stream listener every minute. A settlement frame immediately triggers a lookup of final realized P&L and starts the callback as soon as the final outcome is available. While waiting for the final record or during a stream disconnect, the worker checks again every five seconds. Phone and browser sessions can be closed. The daily cron is a recovery scan for older missed records. A final YES/NO resolution qualifies even if Gemini has not supplied realized P&L. The call reports the verified outcome and identifies any missing amount. A private Blob reservation is created before the outbound API request, keyed by account, contract, outcome and settlement time. Multiple scans cannot ring twice for the same settlement. An ambiguous submission is held for operator review. The optional accepted record contains the provider identifiers. Review call history before any manual follow-up.
