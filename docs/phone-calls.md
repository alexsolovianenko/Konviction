# Konviction telephone calls

Konviction uses a dedicated telephone branch of the existing ElevenLabs agent. Native Twilio delivers the call. Market search and quotes use the public Gemini Sandbox endpoints. Server tools verify that ElevenLabs is handling the active Twilio call on the expected number and branch. Inbound callers share a public sandbox demo. Each conversation has its own proposals and spoken approvals.

## Operator setup

1. Set server-only environment variables in the existing Vercel project. Keep the existing ElevenLabs, voice confirmation and Blob credentials. Set `ELEVENLABS_PHONE_BRANCH_ID` to the dedicated branch and `ELEVENLABS_PHONE_NUMBER_ID` to the imported phone ID and `CRON_SECRET` to a random secret. For number provisioning only, run `node scripts/connect-twilio.mjs` in a trusted environment containing `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`, `ELEVENLABS_API_KEY`, `ELEVENLABS_AGENT_ID` and `ELEVENLABS_PHONE_BRANCH_ID`. ElevenLabs stores the native Twilio credential. The application runtime needs only the ElevenLabs credential for dialing.
2. Set the phone demo’s server-side `PHONE_DEMO_GEMINI_API_KEY` and `PHONE_DEMO_GEMINI_API_SECRET`. To explicitly use the website’s public sandbox demo instead, set `PHONE_SANDBOX_ACCOUNT=website-demo`. Everyone who calls can use the selected demo account. Inbound calls never select a private subscriber account.
3. Optional outbound notifications use `PHONE_ACCOUNTS_JSON` records with a stable unique `id`, verified E.164 `phone`, dedicated sandbox `apiKey` and `apiSecret`, and consent timestamp `notifySince`. The callback can read only its own reserved settlement.
4. Run `node scripts/publish-phone-tools.mjs` with the existing agent environment. It derives the production origin and workspace-secret reference from the existing hosted trading confirmation tool. It publishes only telephone webhooks and the regular website voice and greeting to the telephone branch. After deploying the phone endpoints, run the number connection script to bind Twilio to that branch. Inbound callers can request a research quote immediately. Purchasing research and submitting orders each require their own spoken approval.
5. Verify a real inbound call, portfolio lookup and a separate exact proposal readback. Test one outbound settlement with a consenting registered owner. Canadian and US registrations retain their international +1 number while traveling.

## Settlement delivery

A Vercel Queue renews an authenticated Gemini Sandbox position-stream listener every minute. A settlement frame immediately triggers a lookup of final realized P&L and starts the callback as soon as the final outcome is available. While waiting for the final record or during a stream disconnect, the worker checks again every five seconds. Phone and browser sessions can be closed. The daily cron is a recovery scan for older missed records. A final YES/NO resolution qualifies even if Gemini has not supplied realized P&L. The call reports the verified outcome and identifies any missing amount. A private Blob reservation is created before the outbound API request, keyed by account, contract, outcome and settlement time. Multiple scans cannot ring twice for the same settlement. An ambiguous submission is held for operator review. The optional accepted record contains the provider identifiers. Review call history before any manual follow-up.
