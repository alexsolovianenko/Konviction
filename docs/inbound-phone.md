# Call the Gemini sandbox

This Node launcher answers a Twilio Programmable Voice number. Twilio handles speech recognition and reads prompts aloud. ElevenLabs powers the separate browser experience. Phone orders are immediate-or-cancel sandbox buys and share the browser's SQLite risk ledger.

The browser launcher runs ElevenLabs only. The phone implementation is retained separately for future use.

1. Install dependencies with `npm ci`. In the launcher's private environment, set `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, and `TWILIO_FROM_NUMBER` for the account that owns a voice-capable Twilio number. Set `PHONE_OWNER_NUMBER` to the authorized caller's E.164 number. These are two different numbers.
2. Forward a public HTTPS origin with a publicly trusted certificate to **only** `127.0.0.1:8788` on the launcher machine. Set `PHONE_PUBLIC_ORIGIN` to that exact origin, e.g. `https://voice.example.org`, without a trailing slash. Set `PHONE_PORT` if changing the loopback port. Preserve the webhook path and POST body and disable proxy request-body logging. Set `PUBLIC_PHONE_NUMBER` to the Twilio number if displaying it in the dashboard.
3. Configure `GEMINI_API_KEY` and `GEMINI_API_SECRET` for the sandbox account. Positions require account read access. To permit orders set `EXECUTION_ENABLED=true` and use a sandbox key with trading permission. The existing `MAX_ORDER_USD`, `MAX_DAILY_USD`, `MAX_QUANTITY`, and `MAX_LIMIT_PRICE` apply to phone and browser approvals. Start `npm run dev` with a persistent `SQLITE_PATH`. Leaving `PHONE_PUBLIC_ORIGIN` empty disables the phone listener.
4. In **Twilio Console → Phone Numbers → Manage → Active numbers → your number → Voice configuration**, select **Webhook** for **A call comes in**, enter `https://voice.example.org/phone/incoming`, and select **HTTP POST**. Set **Call status changes** to `https://voice.example.org/phone/status`, also **HTTP POST**, then save. Assign this number to the custom webhook and keep recordings off. [Twilio voice webhooks](https://www.twilio.com/docs/usage/webhooks/voice-webhooks)
5. On the trusted host, from this repo with the same environment and database, run `node scripts/pair-phone.mjs`. Dial the Twilio number from the authorized phone and enter the eight digits on the keypad. Each code lasts five minutes and grants one call. Issuing another code replaces the previous one. Three wrong guesses exhaust a code across calls. Keep the code private.
6. Say “Bitcoin up in five minutes” or “pull up SOL,” then “option one.” Listen to the YES and NO asks. Say “buy ten dollars of yes,” “buy two contracts of no,” or “buy yes” and then the quantity. Listen to the complete readback and say “confirm” or “cancel.” Say “positions” at the menu or “done” to hang up. Availability depends on the sandbox feed and liquidity.

## Research and verification

- **Telephony research.** Twilio signs the exact webhook URL and form parameters with the owning account's Auth Token. This listener validates with the Twilio SDK against its configured public origin. A slow operation returns a TwiML redirect that references its server-issued turn. The custom TwiML route uses Twilio speech directly. ElevenLabs native import assigns the number to an ElevenLabs agent and is a separate inbound routing option. [Twilio request validation](https://www.twilio.com/docs/usage/security) · [Gather](https://www.twilio.com/docs/voice/twiml/gather) · [Voice webhook timeout](https://www.twilio.com/docs/usage/webhooks/webhooks-connection-overrides) · [ElevenLabs native import](https://elevenlabs.io/docs/eleven-agents/phone-numbers/twilio-integration/native-integration)
- **Authorization and execution research.** Caller ID alone cannot authorize a trade. Pairing binds an owner to a call after keypad redemption. Each server-issued turn can advance once. The shared SQLite proposal owner, expiry check and atomic spend reservation bind confirmation to the spoken quote. The existing engine rechecks the exchange quote before submitting. Unknown outcomes keep their reservation. After a crash or an unknown result, check sandbox order history before placing another order.
- **Local verification.** Run `node --test server/phone-server.test.mjs`. The test posts SDK-signed form fixtures over loopback, restarts the listener against the same SQLite file, and exercises the real trade engine against a mocked Gemini sandbox transport. Public routing, phone audio, and exchange account permissions require provisioned accounts and a separately authorized call.
